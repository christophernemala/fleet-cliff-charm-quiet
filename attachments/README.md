# Convergint Proforma Skill Package

Files:

- `SKILL.md`: complete reusable operating instructions.
- `convergint_proforma.schema.json`: strict JSON data contract.
- `example_input.json`: approved example for the AED 83,471.61 consolidated proforma.
- `PROJECT_INSTRUCTIONS.txt`: concise instructions for ChatGPT Projects, a custom GPT, or Copilot Studio.
- `reference_proforma.pdf`: current corrected Dubai bank-details proforma.

Recommended use:

1. Upload all five files to one ChatGPT Project or custom GPT.
2. Put the content of `PROJECT_INSTRUCTIONS.txt` in the Project or GPT instruction field.
3. For each new proforma, upload the source invoice, SOA, LPO, or Excel file.
4. Ask the assistant to create a JSON file conforming to the schema first, validate it, and then generate the PDF.
5. Keep the reference PDF as the visual master.
